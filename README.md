# Jeyson Dagondon, RPh

**Healthcare workflow automation** — I run the operations layer of a US telehealth clinic, and I build the tools that remove manual work from it.

I'm a Registered Pharmacist (PRC, board rating 91.07%) working remotely for a US peptide/GLP-1 telehealth clinic. My day job is the full patient and prescription pipeline in Zoho CRM — records, refills, and order coordination with US compounding pharmacies. The other half of the job is a **45+ script Tampermonkey userscript and Chrome extension suite** that automates intake, order queues, tracking, and address validation across the clinic's CRM, patient portal, and pharmacy portals.

I read protocols, catch dosing discrepancies, and build the systems that keep them from recurring.

### Selected work

**[userscript-showcase](https://github.com/anki-boi/userscript-showcase)** — A production browser-automation suite for clinical admin, mirrored for review: 34 Tampermonkey userscripts driving a CRM, a patient portal, and seven pharmacy portals. The interesting parts are the patterns — SPA wait strategies, virtualized-list harvesting, cross-origin tab handoff, and PDF form fill. Every client identifier is replaced with a fictional host, so it reads as a code showcase rather than a runnable demo.

**[True-Anki-MCQ-Note-Template](https://github.com/anki-boi/True-Anki-MCQ-Note-Template)** ★ 15 — Responsive HTML/CSS/JS Anki card template with randomized order, multi-answer support, and visual feedback. The card I wish I'd had in pharmacy school.

**[Anki-MCQ-Importer-AI-Batch-Generator](https://github.com/anki-boi/Anki-MCQ-Importer-AI-Batch-Generator)** — Python + Gemini API add-on that batch-processes folders of study images into structured, high-yield MCQ flashcards with organized subdecks.

**[ojph-cleaner](https://github.com/anki-boi/ojph-cleaner)** — Manifest V3 Chrome extension that filters job listings on OnlineJobs.ph by salary and keyword, with a deep scan of full descriptions and a user-editable rules engine.

**[datecard](https://github.com/anki-boi/datecard)** — QR-based dating card product for the PH market. React + Vite + Supabase, demo-mode without credentials, MIT licensed.
